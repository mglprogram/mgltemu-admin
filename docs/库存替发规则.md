# TEMU 修改库存 · 替发/拆解规则库

> 数据源：`config/temu_stock_rules.json`（BEL / BHY **两店共用**）
> 读取：`scripts/goods/substitute_rules.py`
> 用户口述时间：2026-11-18；以后改规则**只改 JSON**，不要改代码。

## 1. 为什么需要这个库

同一个海外仓的货，常常可以顶替好几个「款号-套系」卖出去（替发），一个套装也可能由几个
单件拆出来（拆解）。以前 `presale_plan.py` 只看**本款本尺码**的可用库存，于是把
「本款 0、同组别款还有 200 件」的款判成「该清零 / 该开预售」，白丢销量，也被用户反复纠正
（2038-4SetA、202201-5SetA、204203-4SetA 都是这么发现的）。

现在计划先算「本款可用」，**吃紧时**再看同组：取组内**最大的一份**（不相加，避免同一批货被
两个款重复挂账）。

## 2. 三种规则

| 写法 | 含义 | 例子 |
|---|---|---|
| `2038-4SetA` | 明确的**一个套系** | 只跟 `2038-4SetB` 互顶，`2038-4SetC` 不参与 |
| `2032-所有变体` | 该款号下**全部套系** | `2032-4SetA/4SetB/5SetA…` 任意两个都能互顶 |
| `recipes` | **拆解/组合**（单向） | `102303-6SetA = 102302-3BHW×1 + (5SetA 或 5SetB)×1`，或 `3BHW×2` |

几条硬口径：

1. **双向**。写 `A ↔ B` 就等于 B 也能用 A 的货。
2. **取最大、不相加**。组内 5 个款各有 100 件，不是 500 件，是 100 件。
3. **只在吃紧时才算**：本款该尺码 `可用 <= 0` 或 `可售天数 <= borrow_days`（默认 3 天）。
   本款本来够卖就不动，免得把别款的货天天挂到自己头上。
4. **规则分几行写会自动并组**：`304002-3B ↔ 3040A-3B` 与 `T3038-3B ↔ 3040A-3B` 合成一组之后，
   `304002-3B` 与 `T3038-3B` 也互通。
5. **拆解取最优组合**：一个 target 可以写多种 `variants`，算出来取最大的那种。

## 4. 对「清零 / 开预售」计划的影响

`presale_plan.build()` 现在的算法（v3 + 替发）：

```
avail_本款 = 恒信可用 + 帕沃尔加州3 + Kansas
avail_生效 = 本款吃紧时 max(avail_本款, 组内最大一份, 可拆解量)
D0 = avail_生效 ÷ 7天日均
L  = 最早一票在途的预测上架日 − 今天
```

判定：

| 条件 | 动作 |
|---|---|
| `D0 <= 1 天`（硬线） | 清零；在途 7 天内到 → 同时开预售 |
| `D0 >= L + 2` | 不动 |
| `D0 >= 7 天`（且没有更近的到货） | **不动**（本次新增，见下） |
| `D0 < L+2` 且 `ETA <= 7` | 清零 + 开预售 |
| 其余（含无在途） | 只清零 |

每次判定都会在结果里留 `availRaw` / `avail` / `subFrom`，面板的「计算依据」能看到
「含替发 202504-5SetB」这类来源。

### 顺带修掉的一个老 bug

旧口径「无在途 → 一律只清零」漏了 D0 这道闸：`1091-1B`、`205304-5SetA`、`102105-3BGR`
这些**仓里还有 200~1100 天库存**的款也被列进「待清零」，一共 82 条垃圾待办。
现在只要「没有更近的到货」且 `D0 >= 7 天`，就不动。

## 5. 怎么用 / 怎么改

```bash
# 校验规则能不能在在售款里落地（不在售的款号会点名，不是错误）
python scripts/goods/substitute_rules.py --check

# 这款跟谁可互顶、各组现货、能怎么拆
python scripts/goods/substitute_rules.py --of 202504-5SetB

# 两款能不能互顶
python scripts/goods/substitute_rules.py --pair 2032-4SetB 207802-4SetA

# 全量分组 + 现货
python scripts/goods/substitute_rules.py --report

# 计划：套用替发 / 不套用
python scripts/goods/presale_plan.py
python scripts/goods/presale_plan.py --no-sub

pytest scripts/goods/tests/test_substitute_rules.py -q
```

改规则的三种改法：

1. **加一对款** → 在 `groups` 里新加一个 `{"id": "...", "members": ["A", "B"]}`
2. **整个款号互通** → `members: ["209999-所有变体"]`
3. **套装能拆** → 在 `recipes` 里加 `{"target": ..., "variants": [[{style, qty}, ...]]}`

⚠️ 款号写**去掉店铺前缀**的形式（`202504-5SetA`，不要写 `BEL-202504-5SetA`），模块会自动兼容
带前缀的调用。`R` / `N` / `T` / `BK` 前缀**不自动归一**——要互顶就显式写进组里。
